# AgentForge：28 篇逐日源码讲解

制定日期：2026-10-29。面向：希望有人带着逐步读懂 AgentForge，而不是自己从目录和代码中摸索的学习者。

## 学习目标与节奏

参考 Agent-100-Days 按主题逐课讲解的方式，整理为 **4 周、28 篇独立课文**。每一天都有自己的独立课文：先用通俗语言解释当天知识点，再把当前 AgentForge 的关键源码原文直接放进课文，紧跟逐段说明每一段在做什么、为什么这样设计、它怎样连接前后模块。读课文时不用在讲解和源码文件之间来回切换。课程不要求写代码、运行命令、核对输出或做练习。

读完后应能：

1. 说清 AgentForge 的问题、主要模块和当前能力边界。
2. 沿一次请求说明扫描、索引、路由、检索、上下文、回答校验和持久化如何衔接。
3. 区分 SQLite、PostgreSQL 和 Chroma 保存的数据，以及词法、符号、向量通道的职责。
4. 说明有效引用、静态关系和语义正确性之间的区别。
5. 看源码时知道从哪个入口、类或函数继续追踪，不必独自摸索阅读顺序。

当前目录包含完整 Python 源码和本地 Git 元数据；学习计划不依赖远端历史，也不假定 AgentForge 是 Agent-100-Days 的 fork。这里只借鉴其教学安排，把当前本地 AgentForge 作为贯穿案例。

按自己的速度阅读即可。每课中的文件和函数是有顺序的阅读路线，不是让你自行设计实验；遇到陌生术语时先看本课解释，再跟着对应源码理解它在项目里的位置。

## 当前项目事实：读源码时采用的起点

以下以 `feature/1.1-core` 当前源码为基线。AF-012-MVP 的真实验收是历史记录；分支上的离线测试、用户手工问答和完整真实宿主验收应分别记录。

| 能力 | 学习时应采用的表述 | 主要依据 |
|---|---|---|
| 扫描、切块与代码索引 | 文件、分块、符号和静态关系保存在项目 SQLite；词法/符号检索可离线运行 | `scanner.py`、`chunker.py`、`store.py`、`retriever.py` |
| 仓库与会话 | SQLite 仓库目录维护本地注册、活动仓库及各索引路径；PostgreSQL 保存会话、消息、摘要和 Memory 所需的仓库身份及状态 | `repositories.py`、`af012_schema.py`、`conversation_store.py`、`conversation_console.py` |
| 向量检索 | 本地 Chroma 持久化代码/文档与 Memory 向量；候选必须回查 SQLite 或 PostgreSQL 权威数据 | `af012_runtime.py`、`embeddings/chroma_index.py`、`memory_retrieval.py` |
| 长期 Memory | 提案须用户审批；PostgreSQL 是权威状态，outbox 同步 Chroma；支持仓库专属和全局作用域，并在查询时复核状态、来源和哈希 | `memory_extraction.py`、`memory_store.py`、`memory_retrieval.py` |
| Python 符号、导入/调用与包关系 | 静态分析；部分结果可能不确定，不能代表运行时关系 | `parsers/`、`package_relations.py` |
| 检索与 Agent 入口 | `search` 是词法查询；`ask` 使用产品意图路由，可按意图选择符号、PackageRelation、词法及可选 Vector；`agent` 是独立的确定性只读工具循环，不调用聊天 Provider | `cli.py`、`product_retrieval.py`、`agent_loop.py` |
| 本地真实问答 | AF-011 有真实问答验收；AF-012-MVP 另记录真实 Qwen Chat/Embedding 与 PostgreSQL/Chroma 联合验收。结论均限于各自案例 | [AF-011 报告](../RELEASE_NOTES.md)、[AF-012-MVP 报告](../RELEASE_NOTES.md) |
| 有限步工具循环 | 已有确定性离线 Planner；真实模型自主选择工具尚未验收 | `agent_loop.py`、[路线记录](../ROADMAP.md) |
| Embedding / RRF | 有向量实现、真实历史实验与 RRF 原型；没有证明普遍优于词法，RRF 产品化仍暂缓 | [泛化结果](../RELEASE_NOTES.md)、[产品进入评测](../RELEASE_NOTES.md) |
| AF-012-MVP 回归 | 保存的最新完整回归为 344 项运行、338 通过、0 失败、0 错误、6 项 Windows 链接权限跳过；另有 24/24 项真实宿主检查通过 | [最终验收报告](../RELEASE_NOTES.md)、[机器结果](../RELEASE_NOTES.md) |

当前默认行为仍有明确边界：控制台可用 `/chroma on` 在本次运行启用 Chroma，也可由启动环境的 `AGENTFORGE_CHROMA_ENABLED=1` 初始化启用；`/chroma index` 负责同步当前索引快照。结构化 PackageRelation 由产品路由在导入、调用和公开 API 等关系意图下选择，不是对所有查询做融合；RRF 与生产拒答阈值没有启用。Memory 要经过用户批准，并由 `/memory sync` 同步向量。Reranker 未实现。

README、ARCHITECTURE、ROADMAP 和验收报告中有历史阶段内容。遇到矛盾时，把「哪一天、哪个阶段、实现/实验/产品状态」列出来，再核对当前源码与最新专项记录，不把旧失败直接当成当前结论。

## 阅读约定

四周中的每一篇正文都是一节完整的讲解，不是待办清单。文中会先说明概念，再结合本页源码逐步讲清输入、关键判断、数据变化、返回结果，以及这段实现如何接入前后模块；代码摘录之后还会把几段实现串成一次完整执行过程，并说明设计取舍和容易混淆的边界。每课还附有参数与字段说明，解释关键输入、默认值以及调整后会怎样影响行为。这里只需要阅读讲解和源码；不安排代码练习或测试运行。

项目 Python 源码、测试中的注释和文档字符串已改为中文；学习课文内嵌的源码摘录也与当前代码同步。代码标识符、命令、协议字段和模型提示词保持原样，方便和程序实际行为对应。

真实模型、数据库和终端命令都不是这套课程的前提。若你之后想实际使用桌面版，再查 [当前版本实践](CURRENT_PRACTICE.md)；它是操作手册，与课程阅读分开。

## 怎么使用这套教学材料

打开当前周目录页，选择当天的单独课文。课文会带你从概念走到源码：先说明问题是什么，再指出具体函数做了什么，最后解释这一部分如何接入 AgentForge 的整体请求链。你只要跟着阅读，不需要打开 PowerShell、运行测试、准备练习仓库或验证输出。

[CURRENT_PRACTICE.md](CURRENT_PRACTICE.md) 是日后实际操作 AgentForge 时查阅的使用手册，不是学习课程作业；[CONVERSATION_AND_MEMORY.md](CONVERSATION_AND_MEMORY.md) 是会话与记忆主题的深入代码导读，需要时再打开。`PROGRESS.md` 和 `INTERVIEW.md` 均为可选文件。

## 阅读节奏

每课按“概念说明 → 本页嵌入的源码原文 → 逐段讲解 → 本课结论”阅读。遇到不理解的函数，可以先沿着调用处向下看，再回到本课说明；不需要先会写该模块，也不需要完成复盘演示。Week 4 的面试材料仅在你准备求职时使用。关系意图可使用 PackageRelation；本地 Qwen 可在条件满足时生成语义摘要。RRF 和 Reranker 仍不在默认问答流程中。
