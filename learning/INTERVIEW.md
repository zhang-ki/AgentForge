# AgentForge 面试准备单

用途：Day 7 开始逐步填写，Day 27 整理。以下是组织材料的框架，尚未完成的任务不能写成自己的成果。

## 60 秒与 3 分钟介绍

60 秒按四句话组织：

1. **问题**：使用者面对怎样的代码定位或理解任务，为什么只靠模型直接回答不够可靠。
2. **方案**：单仓库只读扫描、索引、按意图检索、证据上下文与独立回答验证如何协作。
3. **本人工作**：实际读懂、重写、验证或改进了哪些模块；挑一个能展示的例子。
4. **证据与限制**：使用了什么输入和检查，得到什么结果，哪些能力仍未验证。

3 分钟版本在中间补充一个设计取舍和一次故障定位。避免逐个念目录名，围绕一次真实问题的流转来讲。

## 重点追问与合格答案要点

| 追问 | 回答中应出现的要点 | 可出示的证据 |
|---|---|---|
| 为什么要 RAG？ | 模型不能天然读取当前仓库；检索提供当前外部证据，但检索会漏召回、证据也可能过期 | Day 1 架构图、Day 6 失败案例 |
| 为什么没一开始用框架？ | 当前标准库实现便于看清合同和控制边界；代价是自己承担适配与维护；框架选择取决于需求 | Provider 接口、学习版实现 |
| 为什么用 SQLite？ | 本地单仓库、结构数据与事务；当前向量扫描规模受限，并非分布式或 ANN 方案 | Day 5 数据变化表、Day 15 数学实验 |
| 如何选 chunk 参数？ | 内容边界、定位准确性、召回、重复和预算之间的权衡，需要按查询与样本测量 | Day 4 窗口对照 |
| 词法、符号与向量有什么差异？ | 字面/路径匹配、精确定义与静态关系、语义候选；适用范围不同，不能仅凭直觉选方案 | Day 11 路由表、Day 18 对照 |
| 为什么 RRF 没直接上线？ | 历史实验的独立收益与拒答目标不够；原型可运行不等于产品效果已证明 | AF009GR5 / AF010PRE 与本人解读 |
| 怎样证明没有幻觉？ | 不能普遍保证；分别验证引用身份、原文新鲜度、合同和语义，证据不足时拒答或限定 | Day 12–13 反例 |
| 什么才是 Agent？ | 规划、工具执行、观察和停止；当前生产 Planner 是确定性的，真实模型工具选择未验收 | Day 20 循环、Day 21 设计 |
| 如何防提示注入？ | 不可信仓库内容不能扩权；执行器独立参数校验、固定工具集合、路径与资源约束；不是只写提示词 | Day 19/23 拒绝案例 |
| 超时和重试怎样设计？ | 区分连接/读取/整体时间；判断副作用和请求是否已发送；有界预算；协作式超时有局限 | Day 20 轨迹、Day 22 故障卡 |
| 如何证明测试足够？ | 正常、异常、边界、隔离与真实环境层次；覆盖率只是一种线索，skip 与 Mock 有明确局限 | Day 24 验证矩阵 |
| 你个人做了什么？ | 分开说明既有代码、本人理解、本人复现、本人新增；能深入解释一个改动及失败样例 | Day 25–26 独立练习与结果 |

## 简历素材的记录格式

不要先追求一句好听的成果描述，先填证据表：

| 项目 | 待本人填写 |
|---|---|
| 本人负责的问题 |  |
| 本人实际实现或修改的模块 |  |
| 设计取舍及理由 |  |
| 数据来源、样本量、环境、测量日期 |  |
| 复现命令或演示步骤 |  |
| 基线与改动后结果 |  |
| 失败案例和局限 |  |
| 哪些内容来自既有项目 |  |

描述句式可用：「针对【具体问题】，我在【个人练习/项目模块】实现【机制】，用【具体输入与验证方式】验证【结果】，目前适用范围为【边界】。」

没有改动前后测量就不写“提升 X%”；没有线上用户就不写“生产落地”；没有亲自实施就不写“从零独立开发整套系统”。学习复现与独立小改进本身可以展示工程能力，关键是经得起追问。

## 历史指标使用说明

- 项目已有一次真实聊天 PASS，可以说“项目记录了该案例的真实验收”，不能说“我已完成普遍正确性验证”。
- 91.41% 行覆盖、86.00% 分支覆盖来自历史覆盖率批次，该批次有 3 个跳过；后续 265/265 为用户宿主确认，缺少保存在工作区的原始日志。引用时分别说明，不拼成同一次完整测量。
- 真实模型问答成功不等于真实模型工具选择成功。离线 Planner、Mock 响应、真实聊天、真实工具循环分别记录。
- 语义相似度、RRF 分数、路由置信等级不直接等于答案真实性或正确概率。

## 8 分钟演示脚本骨架

| 时间 | 演示内容 |
|---|---|
| 0–1 分钟 | 问题与能力范围，展示架构图 |
| 1–3 分钟 | 一次内存索引与检索，展示来源路径、行范围、上下文和离线答案 |
| 3–4 分钟 | 一个不存在的目标，展示无证据处理 |
| 4–5 分钟 | 一个静态分析不确定或伪造引用案例，展示限制与拒绝 |
| 5–7 分钟 | 展示本人小改进、检查样本和一个失败例 |
| 7–8 分钟 | 说明现有结论与下一步验证计划 |

若没有可用模型服务，使用离线演示并明确说明；历史真实模型验收作为独立证据介绍，不伪装成正在实时运行。
